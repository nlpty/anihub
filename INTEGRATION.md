# Anime Hub — интеграция каталога

## Источники данных

- **Shikimori** (`app/services/shikimori.py`) — основной каталог. Публичное
  бесплатное API без токенов, самая большая доступная бесплатная база аниме
  на русском (онгоинги, завершённые, анонсы, жанры, рейтинги, описания).
- **AniLibria** (`app/services/anilibria.py`) — два назначения:
  1. Небольшая добавка свежих онгоингов, которых ещё может не быть в кэше Shikimori.
  2. Источник видеоплеера: по названию тайтла ищется совпадение в AniLibria,
     и если оно есть — отдаётся бесплатный официальный embed-плеер с русской озвучкой.

### Почему не Yummyani и не Kodik

- У `ru.yummyani.me` нет документированного публичного API — сайт отдаёт только
  HTML-страницы. Парсинг HTML с бесплатного Render-инстанса нестабилен (сайт может
  менять вёрстку, ставить защиту от ботов) и не может быть надёжно реализован
  и протестирован без доступа к сети из среды разработки. Если он вам принципиально
  нужен — этот файл описывает ниже, как добавить нового провайдера самостоятельно.
- Kodik даёт лучший охват плееров, но требует персональный API-токен, который
  выдают по ручному запросу — это шаг, который придётся сделать вам самим.
  Модуль легко добавить по аналогии с `anilibria.py`.

## Как это работает (без базы данных)

Сервер не хранит ничего на диске. При старте (`app/services/manager.py`,
`AnimeCatalogManager`) в оперативной памяти собирается объединённый список тайтлов:
онгоинги + анонсы + завершённые с Shikimori, плюс уникальные (по названию) онгоинги
из AniLibria. Дедупликация — по нормализованному названию.

- Быстрый старт: сначала подтягивается небольшой каталог (пару сотен тайтлов),
  чтобы сайт был доступен сразу.
- Затем в фоне докачивается полный каталог (по умолчанию до ~2500 тайтлов).
- Каталог целиком обновляется заново каждые 6 часов (`REFRESH_INTERVAL_SECONDS`
  в `manager.py`).
- На бесплатном Render-инстансе сервер "засыпает" при простое — при следующем
  запросе он проснётся и заново соберёт каталог с нуля (это ожидаемо, БД нет,
  диск эфемерный, память не сохраняется).

## API

- `GET /api/anime/ongoings?limit=200` — онгоинги.
- `GET /api/anime/updates?page=1&limit=12` — завершённые + анонсы (для нижнего блока главной).
- `GET /api/anime/search?q=...&type=ongoing|released|anons` — поиск по всему каталогу.
- `GET /api/anime/{id}` — карточка тайтла.
- `GET /api/anime/{id}/players?episode=1` — плеер для серии (если найден в AniLibria).
- `GET /api/titles/count` — сколько тайтлов сейчас в кэше.
- `POST /api/sync` — принудительно запустить пересборку каталога.
- `GET /api/health` — проверка, что кэш уже собран (`catalog_ready`).

## Добавление нового источника

1. Создать `app/services/<name>.py` с функцией, которая отдаёт список словарей
   в едином формате (см. `_to_unified` в `shikimori.py` — поля `id, title, title_en,
   title_jap, poster, status, episodes_released, episodes_total, rating, genres,
   release_year, description, age_rating, provider`).
2. В `manager.py` подключить его вызов в `refresh()` и добавить в дедупликацию
   по `_norm_title`.
